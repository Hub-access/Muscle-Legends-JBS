# JBS R9i.1 安卓 Delta 兼容修复

本版面向安卓 Delta 做代码兼容检查与修复。**尚无安卓 Delta 真机测试，不能保证任意 Delta 版本都能运行，也不能把 Mac 速度当作手机速度。**

## 直接使用

先退出并重新进入《力量传奇》，完成游戏与 Delta 密钥加载；只执行这条一次，避免旧版会话缓存或两份脚本同时运行。

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Hub-access/Muscle-Legends-JBS/main/releases/JBS-R9i-Delta-2026-10-20/JBS-Fast-R9i-Delta.lua"))()
```

[完整源码](./JBS-Fast-R9i-Delta.lua) · [检查记录](./compatibility.json) · [源码与可复现检查包](./JBS-R9i-Delta-checks.zip)

## 修复范围

只修改独立快速锻炼的原生工具适配器：

1. 原生训练模块改为独立任务读取，主训练循环不用跟着等待。两秒仍未确认就恢复原工具并切回已有兼容训练；两秒是本地等待上限，不是服务器延迟保证。
2. 关闭、超时、角色变化后，让旧加载结果失效，避免迟到回调重新确认已停止的状态。已装备 Pushups 时可在旧版的模拟运行中复现该问题。
3. 原工具恢复未完成时立即撤销训练确认，等待恢复成功后才能继续；补上 Backpack 尚未出现时的空值检查。

不依赖 Mac 路径、Opiumware API、文件读写或帧率设置接口。快速锻炼的发送参数、启动额度、持续节奏和延迟处理沿用 R9i；其余功能与原 R9i 的对应 153,895 字节逐字相同。没有添加降帧操作。

工具或原生模块不可用时，兼容训练仍可使用原工具，但不能声称保留了原生 Pushups 路径的速度优势。此状态会在原有状态显示中显示“兼容训练 · 原工具”。
