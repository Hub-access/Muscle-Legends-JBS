# JBS R7：脚本与快速锻炼实测

本目录包含已在《力量传奇》Mac Opiumware 环境运行的 JBS R7，以及与第二脚本25档进行的 **各5次、每次30秒** 实测结果。

## 脚本与下载

- **[JBS-Fast-R7.lua](./JBS-Fast-R7.lua)**：与实测文件字节一致的完整脚本。
- **[完整资料 ZIP](./JBS-R7-and-Benchmark.zip?raw=true)**：脚本、报告、全部10次测量记录、校准数据、复算程序与校验值。
- [完整实测报告](./BENCHMARK.md) · [机器可读统计](./data/summary.json)

在支持对应 Roblox Luau 接口的执行环境中加载本版本：

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/Hub-access/Muscle-Legends-JBS/main/releases/JBS-R7-2026-10-19/JBS-Fast-R7.lua"))()
```

加载后进入 JBS 面板，自行开启“快速锻炼”。本次测试只使用该功能；未启用重生、换包、购买或其他功能。运行环境要求与兼容性见下文。

## 5次汇总

“±”为5次结果的样本标准差，反映轮间波动。

| 指标 | JBS R7 | 第二脚本25档 |
|---|---:|---:|
| 30秒平均速度 | **56.59 ± 0.17 亿/秒** | **62.55 ± 0.14 亿/秒** |
| 后15秒平均速度 | 44.70 ± 0.16 亿/秒 | 48.69 ± 0.11 亿/秒 |
| 每轮 Ping 中位数的平均值 | 140.54 ± 1.06 ms | 3,773.07 ± 229.64 ms |
| 每轮 Ping P95 的平均值 | 857.76 ± 20.35 ms | 11,179.22 ± 448.75 ms |
| 关闭后恢复等待 | 4.03 ± 0.01 秒 | 49.10 ± 0.59 秒 |
| 包含关闭后增长和恢复等待的效率 | 50.07 ± 0.13 亿/秒 | 47.35 ± 0.22 亿/秒 |

- **30秒平均速度：JBS 慢9.52%**；校准宠物自动成长后慢 **9.49%**。
- **后15秒速度：JBS 慢8.18%**，达到第二脚本的 **91.82%**。
- **Ping：JBS 低约3.63秒，降低96.28%**。Data Ping 不是单个训练请求的确认时间。
- 计入关闭后的增长及恢复等待后，本轮 JBS 效率高约5.75%；这与开启期间速度是两个口径。

## 如何控制测试条件

测试时间：2026-10-19 00:38–00:54，北京时间。只测试快速锻炼，源码均未修改。

- 同账号、同服务器、同角色、同位置、同一个 Weight、同一批宠物和同一 Rep Speed；重生数保持不变。
- 先固定5组成对顺序：JBS→第二、JBS→第二、第二→JBS、JBS→第二、第二→JBS。
- 每轮前后各20次低频校准；单轮校准最大变化0.120%，同组两脚本最大校准差0.122%。
- 每轮结束关闭两脚本，直到力量连续3秒不变且 Ping 低于400ms；下一轮再额外休息20秒。
- 每次重载相同 JBS R7，确保自适应状态不在轮次间继承。
- 全部10次有效，无运行错误；没有因为某轮较慢或 Ping 较高而剔除记录。
- 统计以5轮为样本，不把逐秒采样当作额外的独立试验；77项关键计算经过第二条计算路径复核。

正式测量前取消过一次准备过程，当时完成试验数为0；该记录也保留在 ZIP 中。

## 如何解读

这是 **30秒短测**；后15秒窗口不能替代90秒或更长时间的持续测试。两脚本都有前段较高、后段较低的表现，因此同时列出全程和后半段速度。

本次5轮平均速度的95% t区间为 JBS **56.38–56.80 亿/秒**、第二脚本 **62.38–62.71 亿/秒**。校准后成对速度比为 **90.51%**，95% t区间 **90.33%–90.68%**。区间依赖轮次近似独立等假设；同账号、同服务器的重复测量可能相关。

实际游戏验证仅覆盖 **Mac + Opiumware**；**安卓 Delta 尚未实测**。脚本依赖 Roblox Luau 和执行环境提供的接口，不能据此保证所有设备、服务器或未来客户端版本兼容。

测试所用宠物 Rep Speed 合计为101%。发送次数不等于服务端接受训练次数；本文速度均使用实际力量增长。
